# Ram Sena - Assets Directory

Place your custom sprite sheets, character illustrations, audio files, and tiles here:

- `/assets/sprites/` - Character sprites (Vanar, Riksha/Bear, Shri Ram, Lakshman, Hanuman, Sugreev, Jambavan, Nal, Neel, Rakshasas)
- `/assets/tiles/` - Environmental tiles (Grass, Paths, Trees, Ocean, Sand, Rocks, Shrines)
- `/assets/ui/` - Dialogue frames, borders, crests, icons
- `/assets/audio/` - Devotional ambient sounds, chants, footstep effects
