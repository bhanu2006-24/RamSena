# Ram Sena - Assets Directory & Asset Swap Guide

This folder holds all game media assets (audio, sprites, tiles, and backgrounds).
The game includes automated procedural Web Audio API synthesizers and canvas graphics so that it runs out of the box even before you add your custom files. Whenever you add files with the names below, the game will automatically use them!

## 🎵 Audio Assets (`/assets/audio/`)
- `assets/audio/ram.mp3` - Low volume background devotional music / ambient sitar / flute.
- `assets/audio/hail.mp3` - "Jai Shri Ram!" chant or sacred temple bell chime triggered on Hail.
- `assets/audio/step.mp3` - Gentle footstep audio.
- `assets/audio/gather.mp3` - Item gathering chime.

## 🖼️ Sprite Assets (`/assets/sprites/`)
- `vanar.png` - Vanar monkey character sprite (idle & walking).
- `riksha.png` - Riksha bear character sprite.
- `shri_ram.png` - Divine presence of Maryada Purushottam Shri Ram.
- `lakshman.png` - Shri Lakshman.
- `hanuman.png` - Bhaktaraj Shri Hanuman.
- `sugreev.png` - King Sugreev.
- `jambavan.png` - Wise elder Jambavan.
- `vibhishan.png` - Vibhishan.
- `angad.png` - Prince Angad.
- `nal_neel.png` - Architects Nal & Neel.
- `sushena.png` - Royal physician Sushena Vaidya.
- `rakshasa.png` - Nameless Rakshasa combat enemy.

## 🗺️ Tile Assets (`/assets/tiles/`)
- Environmental textures for grass, sand, stone, ocean water, coconut palms, and yajna altar.
